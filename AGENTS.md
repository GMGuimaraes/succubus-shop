# Instruções de colaboração do projeto

## Sincronização obrigatória com o GitHub

- Remoto oficial: `https://github.com/GMGuimaraes/succubus-shop`
- Antes do primeiro comando de qualquer nova sessão de trabalho ou após um período de inatividade, verificar o estado remoto com `git fetch origin` e comparar `HEAD` com `origin/main`.
- Se `origin/main` tiver commits novos, inspecionar e sincronizar o trabalho antes de editar arquivos, preservando alterações locais existentes.
- Depois de fazer alterações neste projeto, criar um commit contendo apenas as alterações realizadas nesta tarefa e enviar para `origin/main` com `git push origin main`.
- Não incluir no commit alterações locais preexistentes ou arquivos gerados automaticamente sem autorização explícita do usuário.
- Ao relatar o trabalho, informar o resultado da verificação remota e do envio para o GitHub.
